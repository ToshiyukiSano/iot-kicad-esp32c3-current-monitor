# current-monitor 計測ファームウェア 試験計画

対象ファーム：`firmware/current_monitor/current_monitor.ino`（XIAO ESP32C3、A1 = GPIO3）
前提回路：SR-3704-150N（3000:1）、負担抵抗 R1 = 10 Ω、R4 4.7 kΩ + C2 100 nF（fc ≈ 339 Hz）、バイアス ≈ 1.65 V

## 0. 絶対に守ること

1. **CT 二次側を開放したまま一次側に通電しない。** CT リードを J1 に締結してから通電し、巻数変更・CT 取り外し・J1 のネジを緩める作業は、必ず一次側を遮断してから行う。通電中に読み値が突然 0 A 付近に落ちたら、二次側の接触不良を疑い直ちに遮断する。
2. **J1 pin 2 は VBIAS（約 1.65 V）であって GND ではない。** 信号源の COM／アース側を基板 GND・J4 pin 12・XIAO の GND に接続しない。
3. 商用電源の電線を直接 CT に通す試験は行わない。一次電流は絶縁された低電圧交流回路で作る。
4. 信号注入は、フローティングの信号源（電池駆動、または 1:1 絶縁トランス経由）で行う。XIAO を PC の USB から給電する場合は、USB アイソレータまたはモバイルバッテリー給電を使う。

## 1. ファームウェアの使い方

- Arduino IDE：ボードマネージャで **esp32 by Espressif（3.x）** を入れ、ボード「XIAO_ESP32C3」を選択。シリアルモニタ 115200 bps、改行コード「LF」または「CR+LF」。
- 出力（200 ms ごと、CSV）：

  `t_ms,win,irms_A,irms_raw_A,adc_mean_mV,vrms_mV,vmin_mV,vmax_mV,n,fs_Hz,overflows,dt_min_us,dt_max_us,dt_mean_us,clip`

  | 列 | 意味 |
  |---|---|
  | irms_A | 校正済み・ノイズ（2 乗差）補正後の一次電流 |
  | irms_raw_A | 校正済み・ノイズ補正なし（ゼロ電流時はこれがノイズの大きさ） |
  | adc_mean_mV | 区間平均（＝オフセット、差し引き済み） |
  | vrms_mV | ADC 端子の交流 RMS |
  | n / fs_Hz | 区間のサンプル数（400）と実測サンプリング周波数 |
  | overflows | DMA バッファあふれ回数（モード 0）／取りこぼしタイマー割込み数（モード 1）。0 のままが正常 |
  | dt_*_us | モード 1 のみ：サンプリング間隔の実測 最小・最大・平均（µs） |
  | clip | ADC が 100 mV 未満または 2400 mV 超に達した（飽和の恐れ） |

- コマンド（シリアルモニタから入力）：

  | コマンド | 動作 |
  |---|---|
  | `zero [N]` | 0 A で N 区間（既定 50 = 10 秒）測定し、ノイズフロアを設定 |
  | `cal <A> [N]` | 既知電流 <A> を流した状態で校正係数を算出（その後 `zero` をやり直す） |
  | `stat <ラベル> [N]` | N 区間の平均・標準偏差・最小・最大を `#STAT,...` 行で出力し保持 |
  | `cmp` | 保持した統計を並べ、前の行との差と分離指数を `#CMP,...` で出力 |
  | `stream off/on` | CSV の連続出力を止める／再開（統計行は常に出る） |
  | `hz 50/60`、`gain <x>`、`noise <A>`、`save`、`load`、`show`、`clear` | 設定 |

- サンプリング方式（スケッチ先頭の `SAMPLER_MODE`）
  - `0`（推奨・既定）：ESP-IDF の ADC 連続変換（DMA）。ADC をハードウェアで 20 kHz 駆動し 10 個平均 → 2 kHz。間隔はハードウェアで決まるため、`fs_Hz` が 2000.0 付近、`overflows` が 0 であることを確認する。
  - `1`（比較用）：ハードウェアタイマー 2 kHz ＋ `analogReadMilliVolts()`。起動時に 1 回の読み取り時間を表示し、`dt_min/max/mean_us` で実際の間隔を確認できる。Wi-Fi 追加後は揺らぎが増える可能性があるため、本番はモード 0 を使う。

## 2. 期待される測定値（50 Hz、ゲイン 1。ファームは R4/C2 の振幅 0.9893 × 10 点平均 0.9994 = 0.9883 を補正済み）

| 等価一次電流 | 二次電流 | R1 電圧 rms | 出力 vrms_mV | ADC 瞬時値の範囲（バイアス 1650 mV） | 模擬信号 Vgen（Rs = 1.00 kΩ） |
|---|---|---|---|---|---|
| 0 A | 0 | 0 | ノイズのみ | 1650 ± ノイズ | 0 |
| 1 A | 0.333 mA | 3.33 mV | 3.29 | 1645.3〜1654.7 | 0.337 Vrms |
| 5 A | 1.667 mA | 16.67 mV | 16.47 | 1626.7〜1673.3 | 1.683 Vrms |
| 6 A | 2.000 mA | 20.00 mV | 19.77 | 1622.0〜1678.0 | 2.020 Vrms |
| 10 A | 3.333 mA | 33.33 mV | 32.94 | 1603.4〜1696.6 | 3.367 Vrms |
| 20 A | 6.667 mA | 66.67 mV | 65.88 | 1556.7〜1743.3 | Rs = 330 Ω で 2.27 Vrms |
| 80 A | 26.67 mA | 266.7 mV | 263.5 | 1277〜2023 | Rs = 100 Ω で 2.93 Vrms |

- 60 Hz では `hz 60` に設定（振幅 0.9832 を補正）。
- ADC 瞬時値の範囲は R4/C2 通過後のアナログ値（10 点平均前）。
- ゼロ電流時の `irms_raw_A` ≈ 0.304 A × （2 kHz サンプルのノイズ mV rms）。例：ノイズ 1 mV rms → 0.30 A。
- 5 A → 6 A の差：vrms_mV で 3.30 mV。ノイズが白色で 1 サンプルあたり σ mV のとき、1 区間（400 サンプル）の電流値のばらつきは約 0.303 × σ / √400 = 0.015 × σ A。σ = 1 mV なら 0.015 A、σ = 5 mV でも 0.076 A で、1 A の差に対する分離指数（差 ÷ √(σ5² + σ6²)）は σ = 5 mV でも約 9 になる見込み。**ESP32-C3 の実際の ADC ノイズ量は未測定のため、これは計算上の見込み。**
- 合格の目安（提案）：`stat` 50 区間ずつで、校正後に 6 A − 5 A の平均差が 1.00 ± 0.05 A、かつ分離指数 ≥ 5。

## 3. フェーズ A：CT を使わない低電圧模擬信号

### 接続図

```
  フローティング信号源（電池駆動、または 1:1 絶縁トランス経由）
     50/60 Hz 正弦波、DC オフセット 0

     OUT(+) ──────[ Rs = 1.00 kΩ, 0.1 %, 0.25 W ]──────┬───────────►  J1 pin 1  (CT_P)
                        │                 │             │
                        └──── DMM (AC mV, 真の実効値) ──┘   ← 基準：I_inj = V_Rs / Rs
                                                              I_eq = I_inj × 3000

     COM(−) ──────────────────────────────────────────────────────►  J1 pin 2  (VBIAS ≈ 1.65 V)
                                                                       ※ GND ではない

     ✗ COM を 基板 GND / J4 pin 12 / XIAO GND / オシロのアースクリップ に接続しない
     XIAO 給電：モバイルバッテリー、または PC + USB アイソレータ
```

- 注入電流は Rs で制限され、Vgen ≤ 5 V peak・Rs ≥ 1 kΩ なら R1 には最大 ±50 mV しか出ない（D1 のクランプ域より十分低い）。
- 接続後、DMM の DC レンジで「J1 pin 2 − 基板 GND」が約 1.65 V のままであることを確認する。0 V 近くに落ちたら信号源 COM がアース経由で GND につながっている（グラウンドループ）→ 中止して給電・信号源の絶縁を見直す。

### 手順

| # | 内容 | コマンド | 確認項目 |
|---|---|---|---|
| A0 | 信号源未接続で起動 | `show` | `adc_mean_mV` ≈ 1650 ± 30、`fs_Hz` ≈ 2000、`overflows` = 0、`clip` = 0 |
| A1 | ノイズフロア（ゲイン 1） | `zero 50` → `stat 0A_pre 50` | `#ZERO` の noise_rms_A を記録 |
| A2 | 5 A 相当を注入し校正 | `cal 5.000 50`（基準は DMM から計算した I_eq） | `#CAL` の gain が 1 ± 数 % |
| A3 | ノイズフロア再設定・保存 | 信号源を 0 にして `zero 50` → `save` | |
| A4 | 繰り返し比較 | `clear` → 0, 1, 5, 6, 10 A を `stat 0A 50`, `stat 1A 50`, `stat 5A 50`, `stat 6A 50`, `stat 10A 50` → 順番を変えてもう 2 回 → `cmp` | 5A→6A の delta と分離指数、繰り返しの再現性 |
| A5 | 60 Hz | `hz 60` → 5 A・6 A で `stat` → `cmp` → `hz 50` | 50 Hz と同等の差 |
| A6 | 周波数特性（任意） | 5 A 相当の振幅で 150 / 250 / 650 Hz を `stat` | 50 Hz 比で 0.917 / 0.793 / 0.391（RC と 10 点平均の合成。ファームは 50 Hz 用の補正なのでこの比で読み値が下がる） |
| A7 | 給電方法の影響 | バッテリー給電と USB アイソレータ給電で A1 を比較 | ノイズ差 |

（Wi-Fi 実装後は、送信中と停止中で A1・A4 を繰り返し、ノイズと 5A/6A の分離を比較する。）

## 4. フェーズ B：絶縁された低電圧交流負荷で CT を検証

### 接続図

```
  AC 100 V ──[ 絶縁トランス（例：二次 12 VAC、定格 ≥ 3 A、端子カバー付き市販品）]
                         二次側 a ──[ ヒューズ ]──[ 負荷抵抗（例 12 Ω / 25 W 以上）または AC 電子負荷 ]──┐
                                                                                                     │
                                       ┌──[ 基準：真の実効値電流計（直列）またはクランプメータ ]────────┘
                                       │
                         二次側 b ─────┴── 電線を CT の穴に N 回通して戻す（等価電流 = N × ループ電流）

  CT リード（黒・白）── J1 pin 1 / pin 2（ネジ締結を確認してから通電）
  基板・XIAO 側の接続はフェーズ A と同じ（信号源は外す）
```

### 手順

1. **通電前**：CT のフックが「カチッ」と閉じていること、CT リードが J1 に確実に締結されていることを確認。
2. ループ電流を約 1.0 A に設定し、巻数で等価電流を作る：N = 1, 5, 6, 10 → 1, 5, 6, 10 A。**巻数を変えるたびに一次側を遮断する。**
3. 各条件で `stat <ラベル> 50` を 3 回（順番を変えて）→ `cmp`。基準電流は電流計の値 × N。
4. 5 A 相当で `cal <基準A> 50` を行い、フェーズ A の gain と比較する（差 ≒ CT の比誤差。仕様は 5 A・10 Ω で 0 ± 0.5 %）。その後 `zero 50` → `save`。
5. 20 A 以上（例：2 A × 10 回、4 A × 20 回 = 80 A）を試す場合は、電線と負荷の発熱に注意し、短時間で行う。

## 5. 未解決事項

1. 本スケッチは**実機で未実行**。（コンパイル結果は報告本文を参照）
2. ESP32-C3 の ADC ノイズ量・直線性は未測定。5 A/6 A の分離は計算上の見込みで、A4・B3 で確認が必要。
3. 校正は ESP32-C3 の eFuse 校正値（カーブフィッティング）に依存する。校正値がないチップでは線形近似になり、起動時に WARNING を出す。
4. 電源 OFF 時の逆給電（BAT54S 経由で 3V3 へ流入）は未解決。フェーズ B で XIAO 無電源のまま CT に通電しないこと。
5. CT 開放時の保護は CT 内蔵 7.5 V ツェナーのみ（電力定格不明）→ 開放通電は禁止。
6. Wi-Fi 送信による ADC ノイズへの影響は Wi-Fi 実装後に評価する。
7. 商用周波数が 50/60 Hz から外れると 200 ms が整数周期にならず、わずかな変動（0.1〜0.2 % 程度の見込み）が出る。
