# 06 — 低電圧試作と測定性能の検証計画

**目的**：基板データの完成だけでなく、電流負荷の変化を再現性よく計測できることを実証する。

## 安全な順序

| 段階 | テスト | 合格判定の例 |
|---|---|---|
| 1 | 目視・テスター導通（電源OFF） | 短絡・誤配線・逆極性なし |
| 2 | USB給電のみ・CTなし | 3V3、VBIASの正常値を確認 |
| 3 | CTなし・低電圧模擬信号 | ADCの平均・RMSが既知入力に追従 |
| 4 | CTを確実に接続した安全な絶縁低電圧交流負荷 | 電流基準計との比較・直線性を測定 |
| 5 | 0A・1A・5A・6A・10Aなど繰り返し | ノイズ分布と変化量が分離できる |
| 6 | Wi-FiのON/OFF・送信中 | 電源変動とADCノイズ増加を把握 |
| 7 | 断電・電源復旧などの異常条件 | 電気設計者が許容範囲を判定。**危険条件を再現して試さない** |

> **禁止**：CT二次側を開放したまま一次側に通電する試験。商用電源の活線に対して自己判断でCT脱着・盤内配線する試験。GPIOを絶対最大定格外に押し込むクランプ試験。

## 計測ログの例

CSV列案：`condition,reference_current_A,measured_current_A,offset_V,noise_rms_A,temperature_C,fs_measured_Hz,overflow_count,notes`。

各条件で同じ時間・同じ回数を測定し、平均値、標準偏差、最大誤差、直線性、50/60Hzでの差を比較します。加工負荷で重要なのは絶対電流だけでなく、**同じ加工条件で5Aと6Aが明瞭に分かれること**です。

## 注意すべき誤差源

- CTの変流比・位相・周波数特性（±0.5%は仕様書に示された特定条件）
- ESP32-C3 ADCの非線形性、ノイズ、アッテネーション、校正
- 1.65VバイアスとWi-Fi電源変動
- 4.7kΩ/100nFの遮断特性と高調波の減衰
- サンプリング周期ゆらぎ、DMAドロップ、Serial/ネットワーク待ち
- CT取付位置で混ざる主軸以外の電流

## 信号注入（CTを使わない）

J1の端子は `CT_P` と `VBIAS` であり、`VBIAS ≠ GND`。CTなし模擬信号には、**接地と独立した絶縁型・電池駆動などの安全な低電圧信号源**を使い、信号源の出力条件と回路の定格を回路設計者が確認してから接続すること。一般の接地型オシロ・信号発生器を、VBIAS-GND間へ確認なくつながないでください。ここでは危険な接続を避けるため固定の注入電圧・配線手順は指定していません。

## CT試験

CT二次側の負担抵抗が接続されたことを**一次側に電流を流す前**に確認します。小電流の試験では絶縁された低電圧交流負荷と基準電流計を使います。一次側の複数ターン巻きによる等価電流の増幅を使う場合も、配線と定格を管理できる試験者が実施します。工作機械の電源への設置はこの試験とは別フェーズです。

## 合格条件を後付けしない

例えば「5Aと6Aの測定区間の95%信頼区間が分離」「繰り返し測定で誤判別率が目標以下」など、検査前に許容誤差と統計的な判断方法を決めます。結果が不十分なら増幅器・外付けADC・フィルタやセンサー定格を見直します。
