# 10 — 基板製造と部品実装（PCBA）を業者へ依頼する

> **参考情報・2026年11月1日作成。** 料金は正式見積もりではありません。発注先・部品在庫・実装面数・手はんだの有無・配送条件・為替・税金で変動します。本プロジェクトは**実機未検証・安全上の未解決事項あり**のため、以下は見積もり調査と製造工程の学習用です。製造発注を推奨するものではありません。

## PCBとPCBAの違い

- **PCB（Printed Circuit Board）**：配線パターン、穴、レジスト、シルクを備えた「部品なし」の基板を製造する。
- **PCBA（Printed Circuit Board Assembly）**：PCBに抵抗・コンデンサ・ダイオード・コネクタなどをはんだ付けして納品する。SMT（表面実装）とTHT（スルーホール／挿入実装）の両方がある。
- **ファームウェア書込み・機能試験**：PCBAと別サービスのことが多い。XIAO ESP32C3はUSB-Cから自分で書き込み、検証する方法が試作では扱いやすい。

## 今回の設計を例にした部品実装範囲

対象は **XIAO ESP32C3、SR-3704-150N、50×40mm・2層・1.6mm基板**。設計の確定値ではなく、KiCadで検討した試作案。

| 区分 | 部品 | 依頼時のポイント |
|---|---|---|
| SMT | R1～R4、C1～C3、BAT54S（D1） | 業者の対応部品番号・テープ形態・片面実装などを確認 |
| DNP | TVS（D2） | **搭載しない**。BOM/CPL/組立指示で未実装を明示 |
| THT | CT端子台（J1）、GPIOヘッダー（J4）、XIAO用1×7ソケット×2 | SMTとは別料金・別工程の可能性がある。自動搭載可とは限らない |
| 手作業でよい | XIAO ESP32C3本体 | 2列ソケットに差し込む構造。モジュール本体は業者実装必須ではない |
| 基板外 | SR-3704-150N（CT）とアンテナ | CTは別途購入・接続。アンテナの取り回しも実物確認 |

> 部品型番候補は [`examples/current-monitor/hardware/bom-candidates.csv`](../examples/current-monitor/hardware/bom-candidates.csv) を参照。**候補は発注可能・実装可能と確認したものではありません。** 実装業者の検索可能な部品番号への置換や、支給部品対応の確認が必要です。

## PCBA見積もりに必要なデータ

| データ | 意味 | KiCadでの準備 |
|---|---|---|
| Gerber（銅箔、レジスト、シルク、外形） | PCB製造用の層データ | PCB Editor → 製造用出力（Plot / Gerber） |
| ドリルデータ（Excellon） | スルーホール・取付穴の加工 | PCB Editor → ドリルファイル生成 |
| BOM.csv | 部品番号、数量、メーカー型番、実装可否 | 回路図からBOM出力。業者指定形式へ整形 |
| CPL.csv / Pick-and-Place | 各SMT部品のX/Y、回転角、表裏 | PCB Editor → 部品位置ファイル出力 |
| 組立図／Assembly Drawing | 極性、向き、DNP、手作業の指示 | PDF・画像等で追加。必要資料は業者ごとに異なる |
| 任意：STEP／組立3D画像 | 高さ・筐体干渉確認 | 今回のXIAO STEPは**近似モデル**、製造上の寸法保証ではない |

**KiCadから出力したBOM・CPLをそのまま見積もりに投入できるとは限りません。** 部品名と業者指定の型番を対応させ、極性部品の向き（D1）、ソケット・端子台、DNPを手動確認します。製造データを出す前には、同じリビジョンの回路図・PCBでERC/DRCを再実行します。

## 5枚製作時の概算費用

**試算の前提：** PCB 5枚、SMT部品は5枚すべて実装。THTも業者実装する案。XIAOとCTを各5個別途購入する想定。送料・税等は予算枠。2026年11月時点の**概算計画値**であり、見積サイトに製造データを投入した結果ではない。

| 項目 | 5枚分の概算 |
|---|---:|
| PCB製造（50×40mm、2層） | 500～2,000円 |
| SMT部品・実装・初期費用 | 3,500～8,500円 |
| THT部品・実装（端子台、ヘッダー、ソケット） | 2,500～7,500円 |
| XIAO ESP32C3 ×5 | 約5,400円（1個1,080円と仮置き） |
| SR-3704-150N ×5 | 約6,400円（1個1,280円と仮置き） |
| 国際送料・税などの予算枠 | 2,500～6,000円 |
| **概算合計** | **20,800～35,900円（約2.1万～3.6万円）** |

これは**PCBA依頼時の価格保証ではない**。特にTHTの対応、部品の最低購入数量、業者の在庫外調達、特殊な実装費、為替、配送料で大きく変動する。設定費・ステンシル費などの最低料金は少量生産時の単価を上げる。

### 代替案

- **A案（SMTのみ業者実装）**：5台分のXIAOとCTも含め、約18,000～30,000円を予算目安。J1/J4/ソケットのTHTは自分ではんだ付け。
- **B案（SMT＋THTも業者実装）**：約21,000～36,000円を予算目安。今回の「部品を載せた状態で納品」に近い。ただしTHT部品と調達が可能か要確認。
- **初号機1台だけ動作確認**：PCBは5枚作っても、XIAOとCTは各1個だけ購入して検証できる。5組購入時より計**約9,440円**を後回しにできる（上の仮単価による計算）。

上のA/Bは**精密な二重見積もりではなく、比較のための価格帯**。配線変更や再製造、工具・試験器、ケース、取付具、検査治具、ファーム書込みの委託費用は含まない。

## オンライン見積もりを取る流れ

1. 未解決の安全項目を棚卸しし、見積もり取得だけを先行するか判断する。
2. Gerber・ドリル・BOM・CPLを**同じ回路リビジョン**から生成し、D2をDNP扱いにする。
3. JLCPCBなどの見積もり画面で、PCBの層数・材質・厚さ・枚数、PCBAの実装面・数量・THT要否を指定する。
4. BOMで**実際に選択できる部品と在庫数**を確認。代替部品は抵抗値だけでなく定格・パッケージ・ピン配置・許容差も一致させる。
5. CPLの回転角、D1の極性、J1の差込方向、XIAOの向き、裏面／表面の指定をプレビューで照合する。
6. 初期費用、実装費、手はんだ費、部品費、送料・税、納期を合算した総額を保存して比較する。
7. 実機の安全評価や試験結果が揃ってから、製造発注を判断する。

## 発注前のチェックリスト

- [ ] CTを外しても二次側開放の危険を生じない運用・回路にしたか
- [ ] XIAO電源OFF時の逆給電リスクとADC入力の保護条件を評価したか
- [ ] 低電圧模擬試験でADCノイズ・5A→6Aの変化の識別を確認したか
- [ ] 部品メーカー品番、購入経路、温度・電圧・電力定格を照合したか
- [ ] 0603等のSMTとTHTの実装工程・費用を業者に確認したか
- [ ] D2はDNP、基板上のJ1/J4/U1ソケットの実装指示に反映したか
- [ ] アンテナ・USB-C・外部CTケーブル・ケース・ネジ穴の干渉を実測したか
- [ ] ERC/DRC、回路図とのネット一致、部品向き・CPLを確認したか
- [ ] 本設計が未検証段階である旨を製造・試験担当に明示したか
