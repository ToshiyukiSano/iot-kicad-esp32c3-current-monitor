# 07 — 安全・未解決事項（必読）

**この設計は教育・低電圧試作段階です。** 産業設備に常設するための保護設計、信頼性評価、法令・社内規格への適合評価は終えていません。

## 必ず解決する項目

| ID | 未解決事項 | なぜ重要か | 次の行動 |
|---|---|---|---|
| S-01 | **CT二次側開放** | R1が基板側のためJ1が外れるとCTは開放される。内蔵7.5Vツェナーの連続定格不明 | CTメーカーへ仕様確認。ケーブル固定・負担抵抗をCT側に置く方式も比較 |
| S-02 | **電源OFF時の逆給電** | BAT54Sから3V3へ注入電流が流れうる | ESP32-C3・XIAOの許容条件と電源回路を検証し、回路構成を変更するか決定 |
| S-03 | **ADC保護** | GPIO注入電流・過電圧の許容条件未確定 | データシート・メーカーに確認、必要なら別の入力保護回路へ変更 |
| S-04 | **CT/工作機械との適合** | 50/60Hz用CTはPWMインバータ出力の精密測定に不向き | 設備の電源構成、負荷範囲、波形帯域を確認 |
| S-05 | **機械的な安全** | 端子台の向き、電線の引張り、筐体固定、アンテナ・USB干渉が未確定 | 実物のCAD・基板・ケースで確認 |
| S-06 | **計測精度** | 低電流・小負荷変化がADCノイズに埋もれる可能性 | 既知電流での校正・再現性・ノイズ測定 |
| S-07 | **BOM品番** | 候補の多くが未照合、入手性未調査 | メーカー品番と実装寸法・温度・定格の再確認 |
| S-08 | **ファームウェア** | Claude作成後のコンパイル・実機動作が未確定 | Coreを固定しコンパイル、時刻精度と欠損を実測 |

## ERC/DRCの「0件」の意味

- ERCはKiCadシンボル上の電気的な接続違反を検出する。
- DRCはクリアランスや未接続など基板設計ルール上の問題を検出する。
- **どちらも、AIが選んだピン番号の物理的正しさ、CT開放時の安全、熱・EMC・ADCの精度を保証しない。** 実際、初期設計ではXIAO右列のピン順が間違っていたが、ERCは通っていました。

## 今回の試験計画から除外した項目

- CT二次側を開放して電圧を測る試験
- GPIOを電源レール外へクランプさせる実機試験（許容条件未確認）
- 工作機械の商用・産業用配電盤での自己判断による設置作業

## 設備導入時の必要条件

産業設備の電気安全・作業手順・適用規格・ノイズ・環境温度・配線保護・筐体・絶縁/接地は、設備管理者・資格/権限のある技術者と個別に確認してください。データ収集装置を作ることと、配電盤に設置して運転を継続できることは別の審査事項です。
